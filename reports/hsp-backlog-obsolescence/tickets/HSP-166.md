# HSP-166: Remove the booking window settings from the unit level

- **Verdict:** not implemented
- **Label:** backlog-review-not-implemented
- **Confidence:** high
- **Checked:** 2026-10-16, scheduled-task batch
- **Jira before write:** created 2023-08-11, updated 2026-01-05 (fix version bump only), no labels, no parent, status To Do.

## Claim

If this ticket were done, `bookingWindowDays` would no longer be editable on a unit (Property / Availability / Booking window
in days). Only the property-level value would exist, and production units would take it from the property.

## Evidence

- The unit-level setting is still there and still overrides the property:
  - `portfolio-manager-service` @ origin/master `2fc96897`, `service/src/json-schemas/unit/availability.json-schema.ts:27-31`
    defines `bookingWindowDays` ("Booking Window in Days") on the unit availability schema.
  - `service/src/prod-units/prod-unit-transformer.service.ts:99`:
    `bookingWindowDays: lmUnit.bookingWindowDays || lmProperty.bookingWindowDays`. Unit wins, property is the fallback.
  - `service/src/lm-units/dto/update-availability.input.ts:8` and `service/src/lm-units/models/lm-units.model.ts:131` still accept it on update.
  - `service/src/shared/event-publishing/unit-event-publishing.service.ts:129-131,859` still publishes unit-level booking
    window change events, and `infra/config/role-permissions.ts:36` still has the `unitBookingWindowChanged` event.
- `kontrol-ui` @ `ea34ed10e`: `libs/kontrol-ui/pages/portfolio/src/lib/components/unit-details/sections.tsx:393`
  lists `bookingWindowDays` as a unit field (`copyable`), and `unit-details/unit-status-change-validation.ts:50` still maps it
  to the UnitAvailability group.
- Property level exists as well (`property-details/ui-schemas.tsx:643`, `service/src/json-schemas/property/availability.json-schema.ts:24`),
  so the "set it on the property" half is already true. The removal half is not.

## Note for review

Not implemented. The mismatch the ticket worried about (unit window differing from property window) is still possible on master.
Newer work, HSP-3042 (ignore the booking window for tenant reservations, 2026-02-09), kept the window logic in place and did
not touch this. Product call: is a unit-level override still wanted (for example for one-off units)?
