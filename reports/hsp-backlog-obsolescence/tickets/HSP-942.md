# HSP-942: Display drafted status tasks in the MC

- **Verdict:** partial (the multi-calendar lists tasks of every status, so a `drafted` task would appear, but nothing draws it as the design asks and nothing in our repos creates drafted tasks)
- **Label:** backlog-review-unclear
- **Confidence:** low
- **Checked:** 2026-10-19, scheduled-task batch
- **Jira before write:** Story, created 2024-04-16, updated 2026-01-05, labels `Designed`, no Repository field, no parent, no links, status To Do, no comments.

## Claim

If this were done, the multi-calendar (MC) would fetch Breezeway (BW) tasks in `drafted` status and show them in the style from the linked Figma file. The "Why" says "we need to create tasks with this status", so something would also have to create drafted tasks.

## Evidence

- The new React MC does not filter by status. `kontrol-ui` @ `ac141aac` `libs/kontrol-ui/pages/multi-calendar/src/lib/stores/multi-calendar-event-store.ts:151` calls the tasks query with only `taskBeginRange`, `taskEndRange` and `unitIds`. No `excludeStatuses`, which `breezeway-sync` @ `4c75e73d` `functions/get-tasks.ts:54` would accept.
- `transformTasksToEvents` (`libs/kontrol-ui/pages/multi-calendar/src/lib/utils/data-transformers.ts:316-336`) copies `breezewayStatus` to `taskStatus` unchanged. `event-renderer.tsx:41` (`RenderedTask`) draws every task the same way and puts the status only in the hover title. No `draft` string anywhere under `pages/multi-calendar`. So a drafted task would show, but with no draft-specific design.
- The legacy Vue MC maps status through `kontrol` @ `cbf3f48d` `src/utils/task.js:13` (`mapTaskStatus`). A `drafted` task becomes `rogue` (no assignees) or `assigned`. No draft state.
- The enum value exists (`TaskStatus.DRAFT = "drafted"` in `@kasadev/enums`) and the reservation tasks overlay labels it "Draft" (`kontrol-ui` `libs/kontrol-ui/pages/reservation-details/src/lib/tasks-and-notes/overlay/details/task-fields.ts:44`, HSP-4045 #3103/#3228, 2026-09/10). That is a different screen.
- Nothing in the HSP repos writes `TaskStatus.DRAFT` or `drafted` (searched all repos in `default-branches.tsv`; only the two kontrol-ui hits above). `breezeway-sync` stores whatever `type_task_status.code` Breezeway sends (`constants/breezeway.ts:836`).
- MC v2 is new (`kontrol-ui` 937394a31, 2026-07-07, #2445), so this ticket predates the screen it targets.
- Not checked: whether any `drafted` task exists in the prod tasks collection, and what the Figma frame shows.
