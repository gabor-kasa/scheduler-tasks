## Claim

If this were done, `remotelock-sync` would request tokens with `grant_type=authorization_code` / `refresh_token`, handle an OAuth callback and store access and refresh tokens, and Portfolio Manager (PM) or Kontrol would have a flow to generate the authorize URL.
