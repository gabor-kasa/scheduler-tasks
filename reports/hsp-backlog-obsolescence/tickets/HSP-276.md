# HSP-276: Add filtering options for Portfolio teams

- **Verdict:** product question (not implemented in code, premise may be moot)
- **Label:** backlog-review-unclear
- **Confidence:** medium
- **Checked:** 2026-10-15, scheduled-task batch

## Claim

If this ticket were done, the Kontrol multi-calendar would have quick filters for: check-ins today, early check-ins
today, check-outs today, units with back-to-back reservations today, and cleaning, maintenance and inspection tasks
today. The stated reason is that Breezeway (BW) is slow and Portfolio teams want to stay in Kontrol.

## Evidence

- `kontrol-ui` @ origin/master `602bc67f1`:
  - `libs/kontrol-ui/pages/multi-calendar/src/lib/models/view-filter.ts:1-7` defines five view filters:
    reservations, blocks, tasks, unassigned row, cleanliness status. These are show/hide toggles, not date-based filters.
  - `libs/kontrol-ui/pages/multi-calendar/src/lib/components/view-filter-menu.tsx:14-20` lists the same five labels.
  - A search for back-to-back, B2B, check-ins today and check-outs today in the multi-calendar lib finds only a code
    comment in `utils/addon-conflicts.ts:19` saying B2B is not handled. No filter exists for any of the seven asks.
  - The multi-calendar filters came in with `937394a31` "Multi-calendar v2 preview" (#2445). No later commit adds the asked-for filters.
- Possible moot premise: `breezeway-sync` @ origin/master `4c75e73` has recent commits "point KASA_OS at tasks.kasa.com"
  (2026-10-14, #966) and "park reservation events skipped for another task manager" (2026-10-15, #968). Tasks appear
  to be moving to another task manager. I did not verify that Breezeway is being retired.

## Note for review

Nothing in code delivers these filters, so this is not obsolete. The ticket is 3 years old, untouched since
2023-09-27, and its reason (BW is slow, Portfolios need task and arrival views) may be answered by the move to the new
task manager. That is a product call, which code cannot show. Question for Adam: do Portfolio teams still want
check-in, check-out, B2B and task filters in the multi-calendar now that tasks are moving off Breezeway?
